## Access Needs of New DAT Members
### First time in the University
- University email address  
- Laptop  
- University ID card  
### From within the University
- Access to LIDA (Fob)  
- Request a phone number from Kim
- Delegate access to team inbox  
	- Snow ticket: [Shared Mailbox Membership](https://leeds.service-now.com/it?id=sc_cat_item&sys_id=1b2644d71baab050d530eb53b24bcb30)
	- Check access to folders  
- Delegate access to DAT Teams group  
	- File --> Add shortcut to OneDrive
- Delegate access to IT portal to make LASER requests  
	- SNow ticket: [Manage my Groups Access to ServiceNow](https://leeds.service-now.com/it?id=sc_cat_item&sys_id=d676e6740fe59f00bb0a079ce1050e75)  
- Delegate access to GitHub and GitLab  
- Add to AD Groups  
	- LRDP-DAT-Admins  
	- LRDP-All-Citrix-Users  
	- LRDP-All-Citrix-SafeRoom-Users 
- Download PRISM and set-up 
- Grant permission as a reviewer on Prism      
- Software on Desktop  
	- Citrix Workspace  
	- SSMS
