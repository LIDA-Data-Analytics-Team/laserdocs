# File transfer methods accessed on DAT02

The firewall rule has been relaxed on Data Transfer Server (DAT02) on LASER to enable file transfer from the following file transfer methods.

### Web browser based:
- Biscom sft - https://laser-sft.leeds.ac.uk/sft
- OneDrive - https://onedrive.live.com/
- CPRD MOVEit - https://mft3.mhra.gov.uk
- DHCW - https://securefileshare.wares.nhs.uk
- SAIL: NHS Wales Data Switching Service - https://nwdss.wales.nhs.uk
- ownCloud - https://cumulus.hir.swan.ac.uk/
- Google Drive - https://drive.google.com/
- NHSD SEFT - https://seftpro.hscic.gov.uk/
- JISC Onlinesurvey - https://www.onlinesurveys.ac.uk
- Snowflake - https://yk60034.eu-west-1.snowflakecomputing.com/ (this authenticates against - https://apps-api.c1.eu-west-1.aws.app.snowflake.com/ and https://app.snowflake.com/)
- DHSC - https://dhsc.egresscloud.com

### AirDnA web browser based:
- reports.s3.amazonaws.com (Pending)
- https://app.airdna.co/data/login 
- https://app.airdna.co/data/ 
- https://app.airdna.co/data/us?lat=40.43509&lng=-96&zoom=3&tab=markets 
- https://app.airdna.co/data/reports
- https://api.airdna.co


### FileZilla-based
- WhenFresh - ftps.whenfresh.com
- UoSheffield FTP - ftp.shef.ac.uk
- Mastercard SFTP - files.mastercard.com
