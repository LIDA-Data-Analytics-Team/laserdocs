# VRE Build Request

To submit a VRE build request, visit [IT Requests](https://it.leeds.ac.uk/it) and login.  
Go to:  
**Request Something --> LASER Requests (*at the left panel*) --> Create Request (*VRE Request - Create*)**

### Provide these details for the project: 
* Project Title, 
* Project ID, 
* Project start Date 
    * Get this from the project proposal
* Project Active Period
    * Get this from the cost estimate
* University Account Code
    * Get this from the project PI/team usually by email if not already provided.
* Lead Researcher/ PI
    * Get this from DMP
* Archive Required/Period/ VRE type and Shared project storage
    * Get this from project cost estimate
* Researcher selection for addition to project
    * Leave blank and do not provide details of researchers here as they will be automatically added to the active directory of the VRE at the VRE build stage. Only include a list of researchers if they have provided a signed copy of the LASER user agreement, evidence of completion of IG training, and written permission from the project PI to be given access to the VRE.
* Annual/Monthly Budget
    * Calculate from the cost estimate spreadsheet
* Alert level
    * 25, 50, 75, 90
* Alert recipients
    * Add PI and main LASER users
* Add additional information if necessary.
