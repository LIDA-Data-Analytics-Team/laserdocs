## DMP  

Send our template DMP to the PI / Lead Applicant to complete.  

	T_02_Data_Management_Plan_v1.4-2.docx
	N:\Academic-Services\ISS\IRC-Data-Services\Processes\ISMS\Work Instructions\supporting-docs\templates

Once returned, check through the document to ensure enough key information is included. Continue the discussion with the researcher and update if required. 

The DMP needs to describe each data asset and each data flow, including:
- what is the data source?
- who is the data controller?
- who is the data processor?
- how will the data be processed?
- what are the expected outputs?
- how long will the data be stored?	
- are there any special requirements for the data?

Save each iteration to the project folder on N: drive, cycling up through version numbers in the file name.

## DPIA  

Ensure that the DPIA screening questions are completed (Annex A - Part A).  
If any of these questions have been answered 'yes' then the DPIA will also need to be completed (Annex A, Part B, Sections 1 & 2).  
A Privacy Notice forms an essential part of the DPIA and must also be completed.  

All Privacy Notices must be sent to [Rebecca Messenger-Clark ](mailto:R.Messenger-Clark@adm.leeds.ac.uk) for approval before they can be published.  
Once approved, we can offer to publish them to the [LIDA website](https://lida.leeds.ac.uk/research-participant-privacy-notice/). If the research team needs this, we can request it from Kim or Karen. Please note there is a 75 character limit on titles of privacy notices published to the LIDA website.  

All DPIAs must be sent to the LIDA IG Manager for review and approval. They are required to complete Annex A, Part B, Sections 3 & 4.
