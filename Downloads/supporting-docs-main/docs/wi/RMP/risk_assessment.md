## Risk Assessment Details  

- Project Information Owner: The owner of the data, as defined as ‘Data Controller’ by the ICO. This should be one or more parties who are controllers of the data set(s). If the data is collected within the organisation it will be ‘The University of Leeds’.  
- Date of next review: Standard review revisit should be 2 years from the date of assessment completion.  

## Data Management Summary  

Describe what the data is, how it will enter LASER and how it will exit LASER.  
For more involved projects with more than one data set, a data flow diagram may need to be created and referenced here.  
The Project Proposal and Data Management Plan will heavily inform this section.  


## Data Classification  

Using the classification definitions outlined in the table, list each distinct data set.  
Add ‘TBC’ in the ‘Asset ID’ column if the data is not already received and recorded in the Information Asset Register.  


## Project Capability Rating  

Add the project required levels of ‘Confidentiality’, ‘Integrity’ and ‘Availability’ on a scale of 1-5.  
Should any level surpass 4, then LASER will not have adequate level of capability to meet demand.  
- Confidentiality:
	1. <= Tier 1
	2. = Tier 2
	3. = Tier 3
	4. = Tier 4
	5. \> Tier 4
- Integrity: Data protection level. This will inform the infrastructure backup requirements.  
- Availability: This will inform the infrastructure replication requirements.  


## Project Risk Rating  

List and assess any risks that the project poses that have not been considered in the LASER Risk Assessment process.  
Where the risk is <= 1.2 list additional ‘Controls in place’.
Where the risk > 1.2 add details of additional controls that will be in place.  


## Project Licence Requirements  

- First table: list _internal_ policies, contracts, laws and data licence agreements that apply to any data used in the project and list the requirements of those contracts and if they can be met.  
- Second table: list _external_ policies, contracts, laws and data licence agreements that apply to
any data used in the project and list the requirements of those contracts and if
they can be met.
