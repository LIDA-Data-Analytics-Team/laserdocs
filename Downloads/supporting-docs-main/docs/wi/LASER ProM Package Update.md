## Updating the ProM Packages within LASER   

Gwil from Client Services has detailed the process for updating the ProM repository packages on the R: drive.  
I think you will only be required to run this once or twice a year.  

- Run the ProM Package Manager from your own PC 
- select all the packages and download them 
  - The files are saved to the following folder: %USERPROFILE%\.ProM610\packages\
- Copy the contents of that folder to the R: drive location R:\ProM610_packages\
