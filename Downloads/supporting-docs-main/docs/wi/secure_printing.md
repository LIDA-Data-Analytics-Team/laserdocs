# Printing from LASER

Printer present in room 11.19.  

This room is bookable and also contains a standard desktop computer, which is not linked to the printer.  

The printer name is '_HP Universal Printing PCL 6 (v7.0.1)_'.  

Printing is only available from DAT02.

```
If the printer is unavailable ("need to install a printer" message appears), it may be necessary to restart the print spool service.  
- Windows start menu --> Services  
- Find 'Print Spooler' and double click
- Change Startup type to 'Manual' or 'Automatic'  
- Click Apply
- Click 'Start'
Printer should now be available.

```

When printing, it's important to select 'Properties' and set a four digit PIN for the documents to be retrieved.  You will be prompted for the PIN again when you click Print and there may be an additional information box to OK through.  

Once the PIN is set and the document printed it will be available to collect from the printer.

On the printer, select print and choose the user id of who sent the job, select the job and enter the PIN.

Collect your printed materials.

Jobs are deleted when they've been printed, or if we delete them manually from the print queue.
