# P0219 Micromobility

## Import pseudonymised VOI data

- P0219 is a tier 3 VRE
- Project receives data from third party provider called VOI, and collects their own questionnaire data associated with the VOI data
- The VOI and questionnaire data is collected from consenting participants, who are identified by their email address used to communicate with the project
- Email addresses are not permitted in the tier 3 VRE as this would increase the asset's data risk to tier 4
- When we receive VOI data we need to pseudonymise the email addresses using a reproducible method to maintain a link across datasets
- Email addresses are pseudonymised using the SHA 256 hash digest of the email address
- There is a Python script that creates a pseudonymised copy of the data
- Go to `\\datstagingdata.file.core.windows.net\incoming` (which I map to I: drive)
- Then go to `P0219/voi_email_pseudonymiser/` and open the Python script
- Using the variables at the top of the script, edit the file paths for the input and output file, and if necessary edit the variable name for the email addresses
- Run the script (required packages are all in base conda env)
- The pseudonymised file should be created where you specified
- Perform the rest of the import as the [data transfer work instruction](../RMP/data_transfer.md) requires to make the pseudonymised version available in the tier 3 VRE

## Import questionnaire data

- The project team have been made aware what pseudonymisation method we use
- They may request an import of questionnaire data that has already been pseudonymised using the same method
- However, if the questionnaire data still contains email addresses, pseudonymise using the same process as above
