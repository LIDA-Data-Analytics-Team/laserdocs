# DynAIRx CPRD Azure Database File Upload Pipeline

The Python script for uploading CPRD data into the Azure database is located at `I:\P0247\_sql_file_upload_scripts`.

Before you run the script, follow these steps:

1. Open the script in an IDE (e.g., PyCharm).
2. Create a new copy of the script and rename it to match the folder you want to upload files from. For example, if you're uploading files from the folder `I:\P0247\2024-04-16\Extract_DruggIssue_001`, rename the script to `drugissue_001.py` and  `I:\P0247\2024-04-16\Extract_DruggIssue_002` rename the script to `drugissue_002.py`.
3. Change the username.
4. Change the file path.
5. Ensure all other parameters remain the same.

To run the code:

1. Open Anaconda Prompt and navigate to the location of the scripts (e.g., `cd I:\P0247\_sql_file_upload_scripts`). Ensure you've updated the parameters mentioned above.
2. Run `python drugissue_###.py`.
3. Any file that has been uploaded will be moved to a new sub folder named `imported_files`

Check to ensure the file upload is running smoothly. When all files in the folder has been uploaded, make a new copy of the script and repeat the same process as above.
