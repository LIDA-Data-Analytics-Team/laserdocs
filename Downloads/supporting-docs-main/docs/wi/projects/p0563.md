# HASP Data Transfer Work Instructions

HASP is a centralised data centre containing datasets sourced from multiple external providers. This document outlines the approved data suppliers, their associated file transfer methods, and the required file naming conventions.

## Data Suppliers
The following suppliers currently provide data to HASP:

- **Locomizer**
- **Whenfresh**
- **AirDNA**
- **MAAP**
  
## File Transfer Methods

### Locomizer
- **Frequency:** Monthly refresh
- **Transfer Method:**
    Locomizer sends AWS download links via Biscom.
    Files can be downloaded manually by copying and pasting each link into a web browser.
    Alternatively, the download process can be automated using the approved script. You can find that in the 'HASP_Code' repo.

### Whenfresh
Whenfresh Data is accessed via platform called Filezilla avaialble on DAT02.
You'll require an SSH key to access the platform. You can find it in 'I:\p0563_whenFresh_ssh'

### AirDNA
**Transfer Method:** Google Drive

### MAAP
**Transfer Method:** Sharepoint 

### File Naming Convention
All data files should follow this naming format: 
HASP_DATA > _NAME_OF_DATA_SUPPLIER > other file identifier
