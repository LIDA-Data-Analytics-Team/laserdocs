# P0299 Asda IGD

## Import data from Asda via SFTP

- Log into DAT02
- Go to `\\datstagingdata.file.core.windows.net\incoming` (which I map to I: drive)
- Then go to P0299 and create a subfolder with today's date
- Open Git Bash
- Change directory to file destination by running:<br>
`cd /i/P0299/<today>/`
- Connect to Asda's SFTP server using the SSH key on I: drive:<br>
`sftp -i ../_importer/.ssh/lida-walmart-rsa SVCMFTELIDAST_GB@mft-prod-ext.wal-mart.com`
- You shouldn't need a password to authenticate, but if you do you can find it in KeePass in the Asda folder
- Once connected, change to FROM_ASDA directory:<br>
`cd FROM_ASDA/`
- Import the files in this folder to the storage on DAT02:<br>
`get <file-name>`
- Once you've got all the files, close the SFTP connection:<br>
`bye`
- Perform the rest of the import as described in the [data transfer work instruction](../RMP/data_transfer.md).
